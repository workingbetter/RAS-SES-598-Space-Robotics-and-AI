## System Description
- Inverted pendulum mounted on a cart
- Cart traversal range: ±2.5m (total range: 5m)
- Pole length: 1m
- Cart mass: 1.0 kg
- Pole mass: 1.0 kg
- Base amplitude: 15.0N (disturbance setting)
- Frequency range: 0.5-4.0 Hz 
- Additional Gaussian noise
